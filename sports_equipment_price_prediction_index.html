This project addresses the problem of predicting the production price of sports equipment. The assignment requires a real-world publicly available dataset and a regression model suitable for continuous prediction. Linear Regression is used because the target variable is a price.

1. Research Problem

Research Question

Can the production price of sports equipment be predicted using production-related features?

Sports equipment can vary considerably in price depending on factors such as materials, manufacturing characteristics, dimensions, production quantity, and labor or processing costs. A predictive model can help identify relationships between these factors and production price.

Objective: Build and evaluate a Linear Regression model that predicts the continuous production price of sports equipment.

4. Linear Regression Model

Linear Regression estimates the relationship between the production price and the selected input features. The trained model is used to predict prices for previously unseen test data. 

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)

Evaluation Metrics

  • R² Score: Measures how much of the variation in production price is explained by the model.
  • RMSE: Measures the typical prediction error in the same units as the target price.
